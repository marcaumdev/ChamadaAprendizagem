# 🎓 Dashboard de Acompanhamento Google (Frequência & Pontualidade)

Painel automatizado de monitoramento de alunos e acompanhamento de chamadas da Google.

## 📊 Funcionalidades do Dashboard Web
- **Filtro de Alunos**: Seleção exclusiva dos alunos marcados como `Google == Sim` (20 Alunos).
- **Ordenação Inteligente**: Ordenados do maior para o menor número de **Faltas** e **Atrasos**.
- **Cartões KPI**: Resumo em tempo real de total de alunos, faltas, atrasos e média por aluno.
- **Gráficos Interativos**: Comparativo gráfico de Faltas x Atrasos (Chart.js).
- **Tabela de Ranking**: Status de frequência com busca instantânea por nome e exportação CSV.

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3 (Vanilla Dark Mode com Glassmorphism)
- JavaScript ES6+ & Chart.js
- Python (Playwright, Pandas, OpenPyXL, Git automation)
